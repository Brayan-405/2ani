## Publicar con GitHub Pages
1. Crea un repo en GitHub y sube todo el contenido de esta carpeta.
2. Settings, luego Pages, Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
3. Tu link será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`
